# Roadmap

1. **Activation**: vertical slice y validación de primera conversación válida en 7 días.
2. **Repetition**: seguimientos, recompra, contenido conversacional.
3. **Social selling**: perfil mínimo, WhatsApp/Instagram, historias, DM y CTA.
4. **Business**: modelo, cliente vs embajador, invitación, presentación, patrocinio y duplicación.
5. **Duplication**: herramientas para enseñar a otra persona el mismo camino.
6. **Leadership**: cohortes, señales de bloqueo, soporte y métricas de equipo.
7. **Generative AI**: capa opcional sobre interfaces de Knowledge Base/compliance existentes.
