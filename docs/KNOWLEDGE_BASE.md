# Elite Focus Knowledge Base

Una fuente de verdad versionada para productos, ingredientes, uso, claims, FAQs, fuentes, recursos y contenido. Todo item tiene estado de aprobación, versión y fuente. El catálogo, Eli, aprendizaje, buscador y compliance leen este mismo modelo.

## Producto en cuatro capas
1. Antes de conversar: contexto, uso aprobado y límites.
2. Para explicar: beneficios autorizados, ingredientes, FAQs, precio y expectativas.
3. Para recomendar: precauciones, evidencia y escalamiento.
4. Dominio: masterclasses, estudios, formulación y actualizaciones.

La capa visible depende del momento del usuario; no se exige completar todo.
