# Elite Focus 2.0

Elite Focus es un sistema operativo para construir el negocio con respeto, servicio y claridad. Su centro no es un curso ni Eli: es el ciclo `usuario → siguiente acción → ejecución → feedback → progreso → repetición`.

## Principios
- Responder siempre “¿qué debo hacer ahora?” con una acción prioritaria.
- Aprender según necesidad y demostrar competencia mediante eventos.
- Separar la experiencia de cliente, embajador, líder y administrador.
- Evitar spam, vigilancia, presión de reclutamiento y claims no aprobados.
- Una única Knowledge Base alimenta catálogo, Eli, formación, contenido y compliance.
